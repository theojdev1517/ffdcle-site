# Family First Defense parking page

A simple static credibility page for Family First Defense, published with GitHub Pages at `www.ffdcle.com`.

The site intentionally avoids promising a final storefront location, hours, services, or detailed opening plans while those items are still being finalized.

The landing-page logo and favicon come from the approved source assets in the Family First Defense project at `branding/logo/`. Update that source first when changing the mark, then refresh the web copies here.
